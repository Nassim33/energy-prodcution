# Project Instructions

React 19 + TypeScript + Vite SPA starter (antd 5, TanStack Router, TanStack Query, Zustand, Zod).

## Commands

Everything is `pnpm` (`pnpm@9`, Node >= 20). The toolchain replaces the ESLint/Prettier defaults:

| Command                        | Notes                                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm dev`                     | Vite dev server                                                                                                                             |
| `pnpm build`                   | `tsc -b` + `vite build`                                                                                                                     |
| `pnpm typecheck`               | `tsc -b --noEmit`                                                                                                                           |
| `pnpm lint`                    | **oxlint** (not ESLint) with `--deny-warnings` — warnings fail, incl. `no-console`. `import/no-cycle` is an error. Config: `.oxlintrc.json` |
| `pnpm format` / `format:check` | **oxfmt** (not Prettier), `.oxfmtrc.jsonc` (printWidth 100, single quotes off, sorted package.json)                                         |
| `pnpm test`                    | Vitest (jsdom + MSW auto-start)                                                                                                             |
| `pnpm generate`                | Regenerate `src/api/gen` from `openapi.yaml` via Kubb                                                                                       |
| `pnpm check`                   | `typecheck && lint && format:check && test` — mirrors CI; run this before pushing                                                           |

Pre-commit hook (husky + lint-staged) runs `oxlint --fix` + `oxfmt` on staged files.

## Generated files — never hand-edit

- `src/routeTree.gen.ts` — regenerated by the TanStack Router Vite plugin on every `pnpm dev`/`pnpm build`. Refer to it from `src/main.tsx` but never edit it.
- `src/api/gen/**` — Kubb output from `openapi.yaml`; gitignored. Re-run `pnpm generate` after spec changes, then swap imports.
- `public/mockServiceWorker.js` — MSW worker (initialized once via `msw init`).

All three are ignored by oxlint/oxfmt/coverage and types included via tsconfig.

## API layer

- Source of truth: `openapi.yaml` at repo root; `kubb.config.ts` wires Kubb (`pluginClient.importPath: "@/lib/api-client"`).
- The hand-written `src/lib/api-client.ts` exports the `client`/`Client` contract Kubb's generated clients call — retries, timeout, `X-CSRFToken` (from `${cookieBaseName}-csrftoken` cookie), `X-Request-ID`, and abort handling all live there. Always route API calls through this client, never raw `fetch` (`RequestConfig.baseURL` overrides the default `/api` base).
- Base URL: `VITE_API_BASE_URL` (default `/api`); cookie base name: `VITE_COOKIE_BASE_NAME` (both in `src/config/app.config.ts`). Copy `.env.example` → `.env`.
- Until real codegen exists, `src/api/posts.ts` is the pattern to copy: hand-written TanStack Query hooks + Zod response validation.
- `VITE_RTE_BASE_URL` points directly at `https://digital.iservices.rte-france.com` (see `.env`). The RTE host does not return CORS headers and rejects browser-origin requests (403) — it must be reached through a server-side proxy in production. A legacy dev proxy `/rte` (same-origin, strips `Origin`/`Referer`) still exists in `vite.config.ts` if you need to fall back to it.

## RTE energy data (this app's core feature)

- Source: RTE open data, endpoint `actual_generations_per_production_type` (`src/api/generation.ts`). Response schema/Zod: `src/schemas/generation.ts` (12 `production_type` values, hourly `values[]` of `{start_date, end_date, updated_date, value}`).
- Auth (OAuth2, see `src/api/generation.ts`): `POST {base}/token/oauth/` with `Authorization: Basic <VITE_RTE_IDENTIFIER>` (base64 `client_id:client_secret`, i.e. the RTE "API key") → cached Bearer token (1h, `getAccessToken`), then `GET ...actual_generations_per_production_type` with `Authorization: Bearer <token>`. Base URL `VITE_RTE_BASE_URL` in `src/config/app.config.ts` (`rteConfig`).
- Runs fully with mocked data in dev + tests: MSW handlers intercept the RTE token endpoint and the RTE host, returning deterministic hourly curves from `src/mocks/generationData.ts` (shared handler in `src/mocks/handlers.ts`). `VITE_ENABLE_MOCKS=true` (`.env`) gates dev mocks.
- Categories/labels/colors for production types: `src/shared/generationMeta.ts`; French number/date formatting: `src/shared/format.ts`, `src/shared/dates.ts`. Charts use recharts (lazy-loaded on the chart route). Never fetch the 7-day window redundantly on both pages: `useActualGenerationQuery` is fed by the shared session window `DEFAULT_WINDOW` (`src/shared/weekWindow.ts`) so the query key matches on home and chart pages.

## Routing & UI

- TanStack Router, file-based routes in `src/routes/` (`__root.tsx`, `index.tsx`, `posts/…`) — fully type-safe; new routes are picked up automatically.
- antd 5 is the UI kit; brand theme tokens live in `src/lib/theme.ts`.
- Path alias `@/*` → `src/*` (tsconfig paths, vite alias, and Kubb all agree).

## Testing

- Setup in `src/test/setup.ts` polyfills `matchMedia` (antd needs it) and `scrollTo` (TanStack Router).
- MSW runs with `onUnhandledRequest: "error"` in tests — every fetch must be covered by `src/mocks/handlers.ts`. Dev-mode mocks are gated by `VITE_ENABLE_MOCKS=true`; handlers are shared between dev + tests.
- Use `renderWithProviders` from `src/test/render.tsx` for components that use router hooks/`Link`/`useParams`.

## TypeScript

- `strict` + `noUncheckedIndexedAccess` — array/object indexing is `undefined`-able; narrow it.
- No `any`; no `@ts-ignore` / `@ts-expect-error`.
- No `useMemo`/`useCallback` by default; follow the Vercel React best practices skill below.
